# 🖥️ Página Teste de Portfólio Iniciante  
Uma página simples de portfólio desenvolvida com **HTML** e **CSS** para desenvolver habilidades através de um projeto.

---

## 🎯 **Objetivo**
Este projeto foi criado para praticar o desenvolvimento web com foco em:
- Estruturação de uma página utilizando **HTML**.
- Estilização e responsividade com **CSS**.

---

## 🚀 **Funcionalidades**
- Estrutura básica de um portfólio.
- Design limpo e responsivo.
- Uso de páginas indexadas.
- Links funcionais para redes sociais e projetos.
- Visualização otimizada para múltiplas telas.
